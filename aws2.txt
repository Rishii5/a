Attach and Permanently Mount EBS (Data Survives Reboot)

🟢 STEP 1: Create Volume (Same as before)

lsblk

nvme0n1 → root disk


nvme1n1 → new disk



🟢 STEP 5: Create Partition
sudo fdisk /dev/nvme1n1
Inside fdisk:
Press:
n
p
Enter
Enter
Enter
w

sudo partprobe

🟢 STEP 6: Format Disk
sudo mkfs.xfs /dev/nvme1n1p1

🟢 STEP 7: Create Mount Folder
sudo mkdir /mnt/data

🟢 STEP 8: Mount Volume
sudo mount /dev/nvme1n1p1 /mnt/data
Check:
df -h

🟢 STEP 9: Make Mount Permanent (VERY IMPORTANT)
Get UUID:
sudo blkid
Copy UUID.
Edit fstab:
sudo nano /etc/fstab
Add line:
UUID=xxxx-xxxx  /mnt/data  xfs  defaults,nofail  0  0
Save and exit.
Test:
sudo mount -a

🟢 STEP 10: Test Persistence
Reboot:
sudo reboot
After login:
df -h
✔️ Volume mounted automatically.

🔹 PART B: Understanding Default Code
AWS Lambda Template:
import json

def lambda_handler(event, context):
    return {
        'statusCode': 200,
        'body': json.dumps('Hello from Lambda!')
    }
Component Explanation: ┌─────────────────┬──────────────────────────────────┐ │ Component │ Meaning │ ├─────────────────┼──────────────────────────────────┤ │ event │ Input data passed to Lambda │ │ context │ Runtime info (memory, request ID)│ │ lambda_handler │ Entry point function │ │ statusCode │ HTTP response code │ │ body │ Output response │ └─────────────────┴──────────────────────────────────┘
🔹 PART C: Write Simple Lambda Program
Example: Add Two Numbers
Delete default code
Copy and paste:
import json

def lambda_handler(event, context):
    # Get input numbers from event
    a = event.get('num1', 0)
    b = event.get('num2', 0)
    
    # Calculate sum
    result = a + b
    
    # Return result
    return {
        'statusCode': 200,
        'body': json.dumps({
            'sum': result
        })
    }
Click Deploy
Wait for: Successfully deployed message

}
✔️ Lambda executed successfully!
